# ポータル実機デザインの仕様

`index.html`（ゲーム置き場）を、**中央に据えた1台の実機へカセットを挿す**形へ作り替える。

## なぜ変えるか

いままではゲームごとにアーケード筐体の絵を1台ずつ用意していた。
筐体は3D・陰影・パース・金属の質感を持つので、**生成AIに同じ型を再現させられない。**
新作のたびに違うデザインの筐体が並び、作り直しになっていた。

実機＋カセット方式なら、**立体物は最初の1回しか作らない。**
ゲームごとに増えるのは平らなラベルの絵だけで、これは生成AIが安定して量産できる。

さらにラベルには**文字を入れさせない**。タイトルはHTML側で重ねて描く。
生成画像の文字は毎回崩れるため（`title-*.webp` を別画像に分けていたのと同じ理由）。

## 発注する画像

素材は `images/portal/` へ置く。元PNGは `images/portal/source/` に残す。
**全て背景は完全透過のPNG**で受け取る（webp変換はこちらでやる）。

| ファイル | サイズ | 何回作るか |
|---|---|---|
| `console-body.png` | 1600 × 900 | **一度だけ** |
| `cartridge-shell.png` | 600 × 800 | **一度だけ**（全ゲーム共通） |
| `cart-label-hell-runner.png` | 800 × 800 | ゲームごと |
| `cart-label-boss-2048.png` | 800 × 800 | ゲームごと |
| `cart-label-hexamine.png` | 800 × 800 | ゲームごと |

**今後の新作で作るのはラベル1枚だけ。**

## 1. 実機本体 `console-body.png`（1600 × 900）

現実には存在しない、アーケードの匂いがする据置ゲーム機。
ファミコンや64のような「横長で低い箱」の骨格に、業務用機の重さを足す。

守ること:

- **正面やや上から見た構図**。カセットを挿す上面が見えている必要がある
- **上面の中央にカセット差込口**（横長のスリット）。ここへ絵の上から
  カセットを重ねるので、**スリットの周りは物を置いていない平らな面にする**
- 前面に**横長の暗いパネル**を設ける。ここへタイトル文字とPLAYを重ねる。
  **文字・ロゴ・数字は一切描かない**
- **全体的に消灯した状態で描く。** LEDやランプは光らせない。
  点灯はCSSでゲームごとの色を乗せるので、最初から光っていると色が混ざる
- 色は無彩色寄り（ガンメタル〜黒）。どのゲームの色を乗せても喧嘩しないように
- 質感は金属とスモークアクリル。角に補強、側面に放熱スリット、太い脚
- 背景は完全透過。影は本体の真下にごく薄く付ける程度

### ChatGPTへの指示文（そのまま貼れる）

```
架空の据置ゲーム機を描いてください。1600×900ピクセル、背景は完全透過（PNG）。

構図:
・正面やや上から見下ろした角度。上面と前面の両方が見えていること
・機体は横長で低い箱型。ファミコンや初期のゲーム機の骨格に、
　業務用アーケード機材の重厚さを足したデザイン

必ず入れる要素:
・上面の中央にカセットの差込口（横長のスリット）。
　スリットの周囲は平らにして、他の部品を置かない
・前面に横長の暗いパネル（表示窓）。中は真っ黒に近い状態
・側面に放熱スリット、角に金属の補強、下部に太い脚

質感と色:
・ガンメタルから黒の無彩色。金属とスモークアクリル
・使い込まれた傷や指紋の質感

重要な制約:
・ランプやLEDは光らせず、すべて消灯した状態で描くこと
・文字、ロゴ、数字、メーカー名の類は一切描かないこと
・背景は完全透過。影は本体の真下にごく薄くだけ

```

## 2. カセットの殻 `cartridge-shell.png`（600 × 800）

全ゲームで使い回す**空のカセット**。ラベル部分はこちらで上から重ねる。

守ること:

- 縦長のカセット。上部に**厚みのある持ち手**、下部に**端子の切り欠き**
- **中央にラベルを貼る四角いくぼみ**を作る。
  くぼみの中は**無地の暗いグレー**にして、模様や文字を描かない
- くぼみは正方形に近い形。カセットの横幅いっぱいではなく、左右に縁を残す
- 色は無彩色（濃いグレーの樹脂）。ゲームごとの色は乗せないこと
- 背景は完全透過

### 指示文

```
架空のゲーム機用カセット（カートリッジ）を正面から描いてください。
600×800ピクセル、背景は完全透過（PNG）。

・縦長の長方形。上部に厚みのある持ち手のリブ、下部に端子の切り欠き
・中央にラベルを貼るための四角いくぼみがある。
　くぼみの中は無地の暗いグレーで塗り、模様も文字も一切描かない
・くぼみは正方形に近い形で、左右に樹脂の縁が残る幅にする
・材質は濃いグレーの樹脂。角に成型の跡や小さな傷
・色は無彩色のみ。特定の色に寄せない
・文字、ロゴ、数字は一切描かない
・背景は完全透過

写実的な3DCG風。正面から見た構図。
```

## 3. ラベルの絵（800 × 800・ゲームごと）

カセットのくぼみに貼る絵。**ここだけがゲームごとに増える。**

守ること:

- **正方形**。ふちまで絵が続いていること（余白や額縁を作らない）
- **文字を一切入れない。** タイトルはHTML側で重ねる
- そのゲームの雰囲気が一目で分かる画。細かい説明より**印象**を優先
- 平面のイラスト。立体物として描かない（カセットの陰影はこちらで付ける）

3本ぶんの内容:

| ゲーム | 描くもの | 色 |
|---|---|---|
| HELL RUNNER | 崩れた足場の上を走る骸骨。背後に炎と荒れた空。追ってくるデビルの影 | 赤・橙・黒 |
| 討伐2048 | 光る数字タイルの盤面と、その奥にそびえる巨大な魔王 | 紫・青 |
| HEXAMINE | 六角形のマスが敷き詰められた盤面。一部がシアンに発光し、奥に分子構造 | シアン・マゼンタ |

### 指示文（HEXAMINEの例）

```
800×800ピクセルの正方形イラストを描いてください。

内容:
六角形のマスが敷き詰められたパズル盤面を、やや斜め上から見た構図。
いくつかのマスがシアン(#20e6ff)に強く発光し、残りのマスは黒く沈んでいる。
盤面の奥に、六角形が結びついた分子構造の模式図がぼんやり光っている。
差し色にマゼンタ(#ff2ba6)を少しだけ使う。

条件:
・文字、数字、ロゴは一切描かない
・絵はキャンバスのふちまで続かせる。余白や額縁を作らない
・平面のイラストとして描く。カセットや紙として立体的に描かない
・全体は暗く、発光している部分だけが際立つ配色
```

他の2本も、内容の段落を差し替えるだけで同じ条件を使う。

## 画面の作り

```
        ┌────┐ ┌────┐ ┌────┐ ┌────┐
        │HELL│ │BOSS│ │HEXA│ │ ?  │   ← カセット置き場
        └────┘ └────┘ └────┘ └────┘
                    │ 選んだものが下りてくる
                    ▼
        ╔═══════════════════════╗
        ║  ▁▁▁▁▁ ← 差込口       ║
        ║  ┌─────────────────┐  ║
        ║  │ HEXAMINE   PLAY │  ║   ← 前面パネル
        ║  └─────────────────┘  ║
        ╚═══════════════════════╝
```

- カセットを押すと、**上から差込口へ下りて挿さる**
- 挿さると前面パネルが**そのゲームの色で点灯**し、タイトル・一行説明・PLAYが出る
- PLAYでゲームへ移動する

### 実装で守ること

- カセットは `<button>`、PLAYは `<a>` にする。**キーボードだけでも辿れること**
- 挿す演出は短く（400ms程度）。演出中でもPLAYは押せるようにする
- 「動きを減らす」設定の環境では、演出を飛ばして即座に挿さった状態にする
- 携帯では横1列に収まらないので、カセット置き場は2列で折り返す
- 未公開のゲーム枠（COMING SOON）は**中身の無いカセット**として残す。
  押しても挿さらず、「準備中」とだけ出す

### 差込口とパネルの位置合わせ

生成された絵の差込口・前面パネルの位置は、指示どおりの座標には来ない。
既存の筐体で `--title-x` などを使って合わせていたのと同じやり方で、
**画像を受け取ってから CSS 変数で詰める**。

```css
--slot-x / --slot-y      /* 差込口の中心 */
--panel-x / --panel-y    /* 前面パネルの左上 */
--panel-w / --panel-h    /* 前面パネルの大きさ */
```

## 進め方

1. 先に **CSSだけで組んだ試作**（`portal-prototype.html`）で操作感を確かめる。
   本体もカセットも仮の図形で置く
2. 画像が揃ったら差し替えて位置を詰める
3. 問題なければ `index.html` を置き換える

**試作が固まるまで `index.html` は触らない。** 公開中のため。

## 注意

- 生成AIは背景を透過にし忘れる。**必ず確認する**
- 「ランプを光らせない」「文字を描かない」は毎回無視される。**確認する**
- ラベルに勝手にタイトルを入れてくることが多い。**確認する**

# 本日の最強決定戦 Remaster
# 画面構成と演出方針

最終更新: 2026-08-27
状態: ユーザー確認済みの採用方針

---

## 1. 通常戦闘の基本構図

戦闘ステージは、**雨のネオン交差点**を採用する。これは現行「本日の最強決定戦」の世界観を受け継ぎつつ、背景・光・地面をRemaster品質へ上げる正統な進化とする。

- 濡れた横断歩道を対戦ラインにする
- 背景は夜の日本風ネオン都市、遠景へ向かう道路、雨、控えめな霧
- 上部中央は、`3 → 2 → 1 → FIGHT`を大きく出すための暗い空として空ける
- 左のプレイヤーと右のNPCは、常に中央を向く左右対面
- カメラは原則として正面寄り。反応ゲームとして、カウント・両キャラ・中央の距離を一目で読めることを優先する

通常戦闘をプレイヤー背後から見る三人称・斜め構図には変更しない。これを採用すると、全7キャラへ背面・前面・斜め向きの待機／ダッシュ／攻撃／勝敗／エフェクトを追加制作する必要があり、現在の横向きモーション資産を捨てることになるため。

## 2. 斜め構図を使う場面

斜め・プレイヤー寄りの構図は採用する。ただし、反応を求める通常戦闘ではなく、**操作を妨げない短い演出専用**に限定する。

| 場面 | 使い方 | 目的 |
| --- | --- | --- |
| 戦闘開始直前 | カウントダウン前に短くプレイヤー側へ寄る。`3`表示前には正面構図へ戻す | 「この交差点へ立った」没入感を作る |
| 決着直後 | 勝者側へ短くカメラを寄せ、勝者の攻撃・勝利ポーズを見せる | 決着の重さを出す |
| ランキング／チャンピオン | 勝者を前景に置く静止画・演出背景として使う | 王者になった達成感を最大化する |

この斜め演出は、既存の横向きバトル素材を新規に背面モーションへ作り替える要求を生まない範囲で使う。背景のパース移動、画面寄り、光、既存ポーズの拡縮・位置調整で表現する。

## 3. 共通カウントダウン演出

信号機は廃止する。背景へ信号・配管・ランプを描かず、画面上部の暗い空間を、Phaser内の大きなネオン文字`3 → 2 → 1 → FIGHT`専用の演出領域にする。

- 背景は雨・街・濡れたアスファルト・前景の横断歩道だけの静止画にする
- カウント文字、発光、短いフラッシュ、画面揺れはすべてPhaserの同じ座標系で描画する
- `FIGHT`だけはシアンとマゼンタの強い発光を使い、反応開始を一目で読めるようにする
- 携帯向けの基準背景は`941 × 1672`。画面下寄りの細いシアン→マゼンタ反射線を戦闘の立ち位置に使う

信号を画像やCSSへ重ねないため、無印で起きた端末ごとのランプ位置ずれそのものをなくす。

## 4. 戦闘UIの採用構成

UIは反応ゲームの情報だけへ絞る。HP、ゲージ、プレイヤー顔、複数の上部HUDは置かない。

### 試合中

- 左右の各キャラの**足元中央**に、プレイヤー名／NPC名を小さく表示する
- 試合中の反応時間、フライング、説明文字は出さない
- カウントと両キャラの見やすさを最優先する

### 決着後

- 各キャラの**頭上**に、そのキャラの結果だけを出す
  - 正常反応: `154ms` のような記録
  - フライング: `FLYING`
- 画面中央には小さな勝利マークまたは短い勝敗表示だけを出す。上部に同じ結果を重複して出さない
- 一定の決着演出後にだけ、画面下へ`RETRY DUEL`と`FIGHTER SELECT`を表示する
- `RETRY DUEL`を主ボタン、`FIGHTER SELECT`を一段控えめな副ボタンにする

### セレクト画面

- ゲーム置き場へ戻る導線は、セレクト画面の左上にだけ`← GAME BASE`として置く
- 対戦中・結果画面にゲーム置き場へ戻る導線は置かない

すべての文字・ボタン・背景・カウント・キャラはPhaserの同じキャンバス座標系へ置く。HTML/CSS側の別座標で重ねない。

## 5. 素材の品質関門（次へ進む条件）

生成プレビューで透明に見えることや、雰囲気が近いことだけでは素材を採用しない。透過検査に失敗した素材は、その後の背景・実装へ流用しない。

### 透明素材

1. ファイルのalphaチャンネル有無を確認する
2. 四隅を含む透明余白のalpha値が`0`であることを確認する
3. 白・黒・実際の戦闘背景へ重ねた3通りを目視する
4. チェッカー模様や単色背景が焼き付いていたら即不採用にする

### 背景とカウントダウンの組み合わせ

1. 背景単体で、上部の空き・左右の街明かり・足場線・横断歩道の前後関係を確認する
2. カウント文字をPhaserで仮置きし、空の中央で十分読めるかを携帯・PCで確認する
3. 足場線と横断歩道が重ならず、キャラ名・スコアを置く余白がその間に残ることを確認する

背景は不透明の完成画像でありalpha検査の対象外とする。キャラ・エフェクトなど透明素材は従来どおりalpha検査を通してから採用する。

どれかが不合格なら、数値を推測して派生素材を量産しない。基準となる背景から作り直す。

## 6. 次の制作順

1. 携帯向けの雨のネオン交差点をPhaserへ仮接続し、`3 → 2 → 1 → FIGHT`を実装する
2. 背景の地面基準線に合わせて、7キャラの足元・頭位置・攻撃エフェクトの最終調整をする
3. PC向けは同じ街・横断歩道の設計で別比率を制作する
4. NEON GATE LINEUP選択画面を、同じ交差点の世界観へ接続する
5. 決着、チャンピオン、ランキング画面へ斜め寄りの演出を追加する

素材を全部作り切ってから実装せず、背景とカウントダウンを仮接続した時点で携帯実機の見やすさを確認する。

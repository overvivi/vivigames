# HELL RUNNER 画像素材の仕様

ChatGPT等で背景・足場を作らせるときの発注仕様。**そのままコピーして使える**プロンプトを各項に用意した。

---

## 0. 前提となるゲーム側の寸法

| 項目 | 値 | 意味 |
|---|---|---|
| 画面 | 縦長(最大幅560px) | スマホ縦持ち前提。横に広い画面にはならない |
| 地面ライン | 画面の上から **68%** | `GROUND_FRAC = 0.68` |
| 背景の表示 | **画面の全高** | 奈落(穴)の部分は背景が下まで見えるため |
| 拡大率 | 端末により 2〜3.5倍 | `devicePixelRatio` を掛けているため |

背景は**高さを画面に合わせて拡大**し、横方向にスクロールさせる。
3:1 の横長画像なら、1画面に見えるのは全体の15%程度で、繰り返しはほとんど気にならない。

---

## 1. 全背景に共通のルール

**これは6枚すべてに必ず入れること。** 特に③⑤⑥は、守られないと使えない。

```
① ドット絵(ピクセルアート)。ドットの粒が見える解像度で、なめらかな写実描写にしない
② 横長。幅:高さ = 3:1(2172 x 724 px 程度。前回と同じサイズでよい)
③ 地平線(遠景の地面と空の境目)を、画像の上から約65%の位置に置く
④ 画像の下35%は「奈落の底」として見える部分。溶岩・深い闇・霧など、
   下方向に続いている感じにする
⑤ 画像の左端と右端の近くには、目立つ建造物やシンボルを置かない。
   端は空と、ありふれた地形だけにする(横に繰り返して使うため)
⑥ 文字・ロゴ・透かし・キャラクター・UIは一切描かない。風景のみ
⑦ 6枚すべてで、ドットの粒の大きさ・陰影のつけ方・遠近感を統一する
   (場面が切り替わるときに重ねてフェードさせるため)
```

**⑤の理由**: 横スクロールで無限に繰り返すため、端に城などを置くと同じ建物が何度も現れて不自然になる。
継ぎ目自体は左右反転して並べる方式で消せるので、**シームレスにする必要はない**。

**⑦の理由**: 背景の切り替えは、2枚を重ねて透明度を変える方式で行う。
絵の描き方(特に地平線の高さとドットの粗さ)が揃っていないと、切り替わりが濁って見える。

## 2. 背景4枚の個別プロンプト

### ① 地獄(0m 〜 16,000m)

初代 `ヘルランナー背景.png` の雰囲気は良かったので**それを踏襲**しつつ、
地平線の位置と、左右端の作りだけを直す。

```
ドット絵(ピクセルアート)の横長背景を作ってください。

【場面】地獄の大地。煮えたぎる溶岩の大河が流れ、断崖から溶岩の滝が幾筋も落ちる。
奥に噴煙を上げる火山。中央やや奥に、尖塔の並ぶ黒い魔城(正面にドクロの意匠)。
空にはコウモリが舞い、鎖で吊られた鉄の檻がいくつも垂れ下がる。
【色】燃えるような赤と橙、影は黒に近い暗褐色。空は分厚い赤黒い雲。
【サイズ】幅2172 x 高さ724 px(横長 3:1)
【構図】地平線(溶岩の大地と赤い空の境目)を、画像の上から約65%の位置に置く。
空を広めに取ること。下35%は溶岩の海と、そこへ落ち込む深い裂け目。
魔城は中央付近に1つだけ置き、左端と右端の近くには火山も城も置かず、
赤い空とありふれた岩山だけにする。
【禁止】文字・ロゴ・透かし・人物やキャラクター・UI。写実的ななめらかな描写。
```

**前回との違いは2点だけ:**
1. 地平線を上から約40% → **約65%** へ下げ、空を広く取る(地面ラインと合わせるため)
2. 左右の端から火山を外す(横に繰り返したとき同じ火山が何度も出るのを防ぐため)

## 3. 足場(地面)の画像化について

**可能。ただし「1枚の絵」ではなく「タイル素材」として発注する必要がある。**

理由は、足場が毎回ランダムに生成されるため。区画の長さも高さもプレイのたびに変わるので、
**繰り返して使える小さな素材**を用意し、こちらでプログラム的に敷き詰める。

必要なのは次の2点。

### ③-A 地面の上端(表面)

```
ドット絵(ピクセルアート)のタイル素材を作ってください。

【用途】横スクロールゲームの地面の「表面」部分。左右に無限に繰り返して使う。
【内容】古い石畳の地面を真横から見た断面の上端。上面に苔と細かなひび。
【サイズ】幅256 x 高さ64 px
【最重要】左端と右端が完全につながること。この画像を横に並べたとき、
継ぎ目がまったく見えないようにする(シームレスタイル)。
【禁止】文字・影の落ち込み・背景(背景は透明か単色)。
```

### ③-B 地面の内部(土や岩)

```
ドット絵(ピクセルアート)のタイル素材を作ってください。

【用途】横スクロールゲームの地面の「内部」。上下左右すべてに繰り返して使う。
【内容】暗い岩と土が詰まった断面。所々に小石と根。
【サイズ】幅256 x 高さ256 px
【最重要】上下左右の四辺すべてが完全につながること(シームレスタイル)。
【禁止】文字・特定方向の光源による強い影・目立つ模様(繰り返しが目立つため)。
```

### 正直なところ

**シームレスタイルは、画像生成AIが最も苦手とする指示のひとつ。** 一発で繋がることはまず無い。

ただし対処できる。繋がらなかった場合は、こちらで**左右反転して並べる**か、
継ぎ目をぼかす加工をすれば実用に耐える。③-Bのような不規則な岩肌は特に誤魔化しが効く。
なので「完璧なタイルが出るまで粘る」必要はなく、**それらしい質感の素材が1枚あれば十分**。

## 4. 納品後の流れ

1. 生成した画像を `images/` に、**下の名前で**入れる

   | # | 背景 | ファイル名 |
   |---|---|---|
   | ① | 地獄 | `bg1-hell.png` |
   | ② | 墓場 | `bg2-graveyard.png` |
   | ③ | 呪いの森 | `bg3-forest.png` |
   | ④ | 滅びた城下町 | `bg4-ruins.png` |
   | ⑤ | 断崖と雲海 | `bg5-cliff.png` |
   | ⑥ | 希望 | `bg6-hope.png` |

2. **縮小しない。生成された原寸のまま置く。**
   縦長画面では画像が約3.5倍に拡大されるため、縮小すると粗が目立つ
   (当初1/2縮小を想定していたが、実機の拡大率を計算した結果この方針に変えた)

## 5. 区間の割り当て

100000m で希望の world に入る前提で、**体感時間が均等になるよう**割り振った。

| # | 背景 | 区間 | 距離幅 | 完全表示 | 合わせた出来事 |
|---|---|---|---|---|---|
| ① | 地獄 | 0 〜 16,000 | 16,000 | 0 〜 15,000 | 転生2500・ライバル5000・滑空10000 |
| ② | 墓場 | 16,000 〜 33,000 | 17,000 | 18,000 〜 31,500 | 十倍界王拳20000・加速開始30000 |
| ③ | 呪いの森 | 33,000 〜 55,000 | 22,000 | 34,500 〜 53,500 | 加速が上限に達する50000 |
| ④ | 滅びた城下町 | 55,000 〜 78,000 | 23,000 | 56,500 〜 76,500 | 朝日が差し始める70000 |
| ⑤ | 断崖と雲海 | 78,000 〜 100,000 | 22,000 | 79,500 〜 98,500 | 夜明けが完成する100000 |
| ⑥ | 希望 | 100,000 〜 ∞ | — | 101,500 〜 | — |

**なぜ後半ほど距離幅が広いのか。** 30000m から加速が始まり、50000m で +40% に達して頭打ちになる。
つまり後半は同じ距離でも早く過ぎるため、距離で均等に割ると後半のゾーンが一瞬で終わってしまう。
速度倍率で割り戻すと、上の5区間はどれも**体感で約16,000m相当**に揃う。

区間の変わり目では、前後の背景を **3,000m かけて重ねながら入れ替える**(急に切り替わらない)。

### 既存の演出との対応

既存の墓石・幽霊・ゾンビ(`drawGraveyard`)と蜘蛛の巣(`drawCursedForest`)は、
今は 7000〜17000m / 17000〜28500m に出る。**背景に合わせて②③の区間へ移動させる。**

空の色変化(`WORLD_STAGES`)と朝日の演出(70000m〜100000m)は残す。
背景画像に薄く色を重ねることで、同じ絵でも距離に応じて明るさが変わるようにする。

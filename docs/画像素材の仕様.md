# HELL RUNNER 画像素材の仕様

ChatGPT等で背景・足場を作らせるときの発注仕様。**そのままコピーして使える**プロンプトを各項に用意した。

---

## 0. 前提となるゲーム側の寸法

| 項目 | 値 | 意味 |
|---|---|---|
| 画面 | 縦長(最大幅560px) | スマホ縦持ち前提。横に広い画面にはならない |
| 地面ライン | 画面の上から **68%** | `GROUND_FRAC = 0.68` |
| 背景の表示 | **画面の全高** | 奈落(穴)の部分は背景が下まで見えるため |
| 拡大率 | 端末により 2〜3.5倍 | `devicePixelRatio` を掛けているため |

背景は**高さを画面に合わせて拡大**し、横方向にスクロールさせる。
3:1 の横長画像なら、1画面に見えるのは全体の15%程度で、繰り返しはほとんど気にならない。

---

## 1. 全背景に共通のルール

**これは4枚すべてに必ず入れること。** 特に③⑤⑥は、守られないと使えない。

```
① ドット絵(ピクセルアート)。ドットの粒が見える解像度で、なめらかな写実描写にしない
② 横長。幅:高さ = 3:1(2172 x 724 px 程度。前回と同じサイズでよい)
③ 地平線(遠景の地面と空の境目)を、画像の上から約65%の位置に置く
④ 画像の下35%は「奈落の底」として見える部分。溶岩・深い闇・霧など、
   下方向に続いている感じにする
⑤ 画像の左端と右端の近くには、目立つ建造物やシンボルを置かない。
   端は空と、ありふれた地形だけにする(横に繰り返して使うため)
⑥ 文字・ロゴ・透かし・キャラクター・UIは一切描かない。風景のみ
⑦ 4枚すべてで、ドットの粒の大きさ・陰影のつけ方・遠近感を統一する
   (場面が切り替わるときに重ねてフェードさせるため)
```

**⑤の理由**: 横スクロールで無限に繰り返すため、端に城などを置くと同じ建物が何度も現れて不自然になる。
継ぎ目自体は左右反転して並べる方式で消せるので、**シームレスにする必要はない**。

**⑦の理由**: 背景の切り替えは、2枚を重ねて透明度を変える方式で行う。
絵の描き方(特に地平線の高さとドットの粗さ)が揃っていないと、切り替わりが濁って見える。

## 2. 背景4枚の個別プロンプト

### ① 地獄(0m 〜)— **作成済み**

`ヘルランナー背景.png` が該当。地平線がやや高い(上から約40%)が、そのまま使える。
作り直す場合は共通ルール③に合わせる。

### ② 墓場(7000m 〜 17000m)

```
ドット絵(ピクセルアート)の横長背景を作ってください。

【場面】荒れ果てた広大な墓地。傾いた墓石が地平線まで並び、朽ちた鉄柵と枯れ木が点在する。
奥に崩れかけた霊廟。地面から冷たい霧が薄く立ちのぼる。
【色】青緑がかった灰色と、くすんだ紫の夜空。差し色に鬼火の淡い緑。
地獄の赤は使わず、体感温度の低い寒色でまとめる。
【サイズ】幅2172 x 高さ724 px(横長 3:1)
【構図】地平線を画像の上から約65%の位置に置く。下35%は霧に沈む地面と暗い奈落。
左端と右端の近くには目立つ建造物を置かず、空と平凡な墓石だけにする。
【禁止】文字・ロゴ・透かし・人物やキャラクター・UI。写実的ななめらかな描写。
```

### ③ 呪いの森(17000m 〜 28500m)

```
ドット絵(ピクセルアート)の横長背景を作ってください。

【場面】呪われた深い森。ねじれた巨木が幾重にも重なり、枝の間に巨大な蜘蛛の巣が張る。
幹には不気味な目のような瘤。地面には毒々しいキノコと絡まる根。奥ほど闇が濃い。
【色】深い緑と黒褐色。差し色に毒々しい紫と、蜘蛛の巣の白。
【サイズ】幅2172 x 高さ724 px(横長 3:1)
【構図】地平線を画像の上から約65%の位置に置く。下35%は根と闇に沈む奈落。
左端と右端の近くには目立つ巨木や巣を置かず、平凡な木立だけにする。
【禁止】文字・ロゴ・透かし・人物やキャラクター・UI。写実的ななめらかな描写。
```

### ④ 希望の world(28500m 〜、70000m以降で完全に切り替わり)

```
ドット絵(ピクセルアート)の横長背景を作ってください。

【場面】どこまでも続く静かな高原。地平線の彼方がわずかに白みはじめ、
薄い雲の切れ間から光の筋が差す。遠くに穏やかな山並みと、小さな石の道標。
禍々しさが消え、これまでの地獄的な要素は一切ない。
【色】藍色から淡い金へのグラデーション。全体に明るく、しかし派手にしない。
【サイズ】幅2172 x 高さ724 px(横長 3:1)
【構図】地平線を画像の上から約65%の位置に置く。下35%は霞んだ谷底。
左端と右端の近くには目立つ山や建造物を置かず、なだらかな稜線だけにする。
【禁止】文字・ロゴ・透かし・人物やキャラクター・UI。写実的ななめらかな描写。
```

## 3. 足場(地面)の画像化について

**可能。ただし「1枚の絵」ではなく「タイル素材」として発注する必要がある。**

理由は、足場が毎回ランダムに生成されるため。区画の長さも高さもプレイのたびに変わるので、
**繰り返して使える小さな素材**を用意し、こちらでプログラム的に敷き詰める。

必要なのは次の2点。

### ③-A 地面の上端(表面)

```
ドット絵(ピクセルアート)のタイル素材を作ってください。

【用途】横スクロールゲームの地面の「表面」部分。左右に無限に繰り返して使う。
【内容】古い石畳の地面を真横から見た断面の上端。上面に苔と細かなひび。
【サイズ】幅256 x 高さ64 px
【最重要】左端と右端が完全につながること。この画像を横に並べたとき、
継ぎ目がまったく見えないようにする(シームレスタイル)。
【禁止】文字・影の落ち込み・背景(背景は透明か単色)。
```

### ③-B 地面の内部(土や岩)

```
ドット絵(ピクセルアート)のタイル素材を作ってください。

【用途】横スクロールゲームの地面の「内部」。上下左右すべてに繰り返して使う。
【内容】暗い岩と土が詰まった断面。所々に小石と根。
【サイズ】幅256 x 高さ256 px
【最重要】上下左右の四辺すべてが完全につながること(シームレスタイル)。
【禁止】文字・特定方向の光源による強い影・目立つ模様(繰り返しが目立つため)。
```

### 正直なところ

**シームレスタイルは、画像生成AIが最も苦手とする指示のひとつ。** 一発で繋がることはまず無い。

ただし対処できる。繋がらなかった場合は、こちらで**左右反転して並べる**か、
継ぎ目をぼかす加工をすれば実用に耐える。③-Bのような不規則な岩肌は特に誤魔化しが効く。
なので「完璧なタイルが出るまで粘る」必要はなく、**それらしい質感の素材が1枚あれば十分**。

---

## 4. 納品後の流れ

1. 生成した画像を `images/` フォルダに入れる(ファイル名は日本語のままで可)
2. **縮小や最適化はこちらで行う**ので、生成時は**最大解像度のまま**渡してよい
3. 画質と読み込みの兼ね合いを見て、1/2縮小(実測で画質劣化はほぼ無し)を基本とする

---

## 5. 区間の割り当て(実装時の予定)

| 距離 | 背景 | 備考 |
|---|---|---|
| 0m 〜 7000m | ① 地獄 | 開幕。題名どおり地獄から始まる |
| 7000m 〜 17000m | ② 墓場 | 既存の墓石・幽霊・ゾンビの演出と同じ区間 |
| 17000m 〜 28500m | ③ 呪いの森 | 既存の蜘蛛の巣の演出と同じ区間 |
| 28500m 〜 | ④ 希望 | ゆっくり移行し、70000m以降で完全に切り替わる |

**28500m以降が長い**(最終的に100000mまで)。ここを1枚で持たせるため、
④は「無限に続く」風景として、繰り返しが目立たない構図にしてある。

既存の空の色変化(`WORLD_STAGES`)と朝日の演出(70000m〜100000m)は残す方針。
背景画像に薄く色を重ねることで、同じ絵でも距離に応じて明るさが変わるようにする。

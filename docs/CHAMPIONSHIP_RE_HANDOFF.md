# CHAMPIONSHIP RE // REMASTER 引き継ぎ（2026-08-28）

## まず結論

旧選択中フレアは **不採用・削除済み**。現在は第二世代の共通レイアウト用素材へ切り替え済み。

添付スクリーンショットのように、選択中NOISEの金フレアが隣のカード領域へ大きくはみ出す状態になっている。これは、途中から背面フレアを追加して解決しようとした結果であり、以下の合意を破っている。

- NORMAL／SELECTは同じ外寸・同じ透明キャラ窓
- 選択時にカードの座標・外寸・操作領域を変えない
- 足りない演出を、後から規格外のレイヤーを重ねて解決しない
- 光・金属の質感は画像素材で担保し、CSSやPhaser図形で代用しない

技術上の透過検査やビルドが通っていても、上のデザイン規格を破るため採用根拠にはならない。この会話では、光量・位置・大きさの数値調整をこれ以上行わない。

## 承認済みの画面構図と規格

- 正式タイトル：`CHAMPIONSHIP RE // REMASTER`
- 上：タイトルロゴ／中：7人横一列の縦長ゲート／下：`START DUEL`
- 大型モニターや選択キャラを中央へ移動する処理は使わない
- 7枚は固定スロット・固定入力領域。選択中だけは、同じ列の中でわずかに手前へ出る奥行き表現を許可する
- Phaser仮想座標は`941×1672`、縦持ち`Scale.ENVELOP`
- 390×844級のSafariで重要要素を安全領域へ置く。ブラウザ下部に掛かる領域は背景だけ

枠本体の現在の規格（変更するなら先にユーザー承認）：

- 本体枠：`100×640`
- 固定中心X：`140, 250, 360, 470, 580, 690, 800`
- 枠中心Y：`850`、下端Y：`1170`

キャラ縦長アートはまだ開始しない。枠と画面構図を実機Safariで承認してから着手する。

## 素材とコードの責務

- 金属枠、選択時の反射・発光・星状フレアは画像素材に描き込む
- Phaserは同一座標での配置、素材切替、入力、画面遷移だけに使う
- 本体の外寸を変える背面レイヤーや、CSSの`box-shadow`で後足ししない
- 背景は自然な濡れた床だけで完成させ、キャラごとの色反射を焼き込まない。選択中だけは短く薄い上下反転の実像反射を重ね、下へ急速に消す
- 50px級の実機縮小で主役感が足りないなら、先に7枚配置・カード幅・選択表現を静止モックで再設計する。数値微調整で済ませない

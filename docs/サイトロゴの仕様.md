# サイトロゴの仕様（VIVI GAME BASE）

サイト名を **VIVI GAME ARCADE** から **VIVI GAME BASE** へ変えたので、ロゴを作り直す。

## なぜ変えるか

ゲーム置き場を「筐体を並べたゲームセンター」から
「1台の実機にカセットを挿す秘密基地」へ作り替えた。
アーケードではなくなったので、名前もロゴもその世界観に合わせる。

文言はすでに差し替え済み（`SELECT YOUR GAME` / `CARTRIDGES` / `VIVI GAME BASE`）。
残っているのはロゴ画像だけ。

## 発注する画像

| ファイル | サイズ | 用途 |
|---|---|---|
| `vivi-game-base-logo.png` | 1600 × 600 | ヒーロー中央の大きなロゴ |

**縦横比 8:3 を守る。** 既存のロゴと同じ比率で、CSSは `object-fit:contain` で
枠に収めているため、比率が変わると余白の付き方が変わる。

背景は**完全透過のPNG**。webp変換は `npm run portal:images` で行う。

## 描くもの

**秘密基地の入口に掛かった金属プレートの看板。**

実機のスケルトンやカセットの発光と同じ理屈で光らせる。
ネオンサインではなく、**金属に彫られた文字が背面から発光している**状態。

- 横長の金属プレート。ガンメタル〜黒。傷や汚れの質感
- そこに **VIVI GAME BASE** の文字が彫り込まれている
- 彫った溝の奥がシアン(#20e6ff)に発光し、文字の輪郭が光って見える
- 差し色にマゼンタ(#ff2ba6)を少しだけ
- プレートの四隅にリベットやボルト。基地の設備らしさを出す

### 文字の組み方

```
   VIVI GAME
      BASE
```

**2段組み**にする。1行に3語を並べると、携帯の幅で文字が小さくなりすぎる。
上段 `VIVI GAME`、下段 `BASE` を大きく。`BASE` が主役。

書体は**角ばった大文字のサンセリフ**。既存サイトのピクセルフォント
（Press Start 2P）と並ぶので、丸い書体は避ける。

### 絶対条件

1. **背景が完全に透過している**
2. **文字は VIVI GAME BASE のみ。** 他の語、型番、記号を足さない
3. **綴りを間違えない**（生成AIが一番外すところ。1文字ずつ確認する）
4. プレートが画像の枠内に収まっている（見切れさせない）
5. 全体が暗く、**発光しているのは文字の溝だけ**

### 指示文（そのまま貼れる）

```
秘密基地の入口に掛かった金属プレートの看板を描いてください。
1600×600ピクセル、背景は完全透過のPNG。

プレート:
・横長の金属プレート。ガンメタルから黒の色。使い込まれた傷や汚れの質感
・四隅にリベットまたはボルト
・プレート全体が画像の中に収まること。見切れさせない

文字:
・「VIVI GAME」を上段、「BASE」を下段に、2段組みで配置する
・下段の BASE を大きくして主役にする
・角ばった大文字のサンセリフ体。丸みのある書体は使わない
・文字は金属に彫り込まれた状態にする

光:
・彫った溝の奥がシアン(#20e6ff)に発光し、文字の輪郭が光って見える
・差し色にマゼンタ(#ff2ba6)をごく少しだけ
・光っているのは文字の溝だけ。プレート自体は光らせない

絶対に守る条件:
・文字は「VIVI GAME BASE」のみ。他の語、型番、記号を一切足さない
・綴りを正確に。V-I-V-I / G-A-M-E / B-A-S-E
・背景は完全透過

写実的な3DCG風。正面から見た構図。
```

### 受け取り時の確認

- [ ] 綴りが正しいか（**1文字ずつ確認する**）
- [ ] 余計な文字や記号が入っていないか
- [ ] 背景が透過か
- [ ] プレートが見切れていないか
- [ ] 縦横比 8:3 か
- [ ] 全体が暗く、光っているのが文字の溝だけか

## 差し替え後の作業

1. 原本を `images/portal/source/vivi-game-base-logo.png` へ置く
2. `tools/portal-images.mjs` の TARGETS へ1行足して `npm run portal:images`
3. `index.html` の参照を `vivi-game-arcade-logo.png` から差し替え
4. 旧ロゴを削除
5. `npm run test:portal` で確認（ロゴが読めない時のフォールバックも検査している）

## 生成AIがよく外すところ

| 外れること | どうなるか |
|---|---|
| 綴り | BASE が BACE、VIVI が VlVl などになる。**必ず1文字ずつ見る** |
| 余計な文字 | 型番や英単語を勝手に足す |
| 背景の透過 | 黒い板が付いてきて、ヒーローの上で四角く浮く |
| 「溝だけ光らせる」 | プレート全体をネオンにしてしまう |
| 2段組み | 1行に詰めてきて、携帯で読めない大きさになる |

# HELL RUNNER 2 実機テスト項目

対象: `games/hell-runner-2.html?debug=1`。PCと携帯の両方で、気になった項目だけでも記録する。
数値調整はDEV TOOLSの`ROGUELITE BALANCE`を使い、良かった値は`COPY ROGUE VALUES`で共有する。

## 1. 最優先: ランの基本感触

- [ ] 2段ジャンプだけで、能力なしでも無理なく遊べる
- [ ] 最初の能力取得は早すぎず遅すぎない
- [ ] 通常の能力取得後、`GO!`の短い猶予で事故なく再開できる
- [ ] 能力取得の停止回数が、走る爽快感を壊していない
- [ ] コインが以前より少なく広くなり、コンボを意識する余地が出た
- [ ] コインとXPオーブが背景に埋もれず、明るさ・大きさとも見つけやすい
- [ ] 飛び越えるべき段差と、走ったまま通れる段差が高低差で直感的に区別できる
- [ ] 跳ぶ必要がある上り壁だけの朱色・金色の縁取りが、視認の助けになり邪魔にならない
- [ ] 空中で越えるべき段差の横壁へ当たっても、壁を通り抜けて落下しない
- [ ] コインとXPオーブの高さ・横位置が、ジャンプや吸引Lvに見合った回収判断になる
- [ ] コインとXPオーブが同じ位置で重ならず、横列・ピラミッド・高所アーチの形を一目で読める
- [ ] コイン・XPオーブのサイズ変更で、見た目に合わせて回収しやすさも変わる
- [ ] 高所コイン率・高所オーブ率を上げた時だけ、奈落上の高い位置の配置が増える
- [ ] 着地できる地面上には、3段ジャンプや吸引を前提にした高所アイテムが出ない

記録: 最初のLEVEL UPまでの距離 / 体感（早い・ちょうどよい・遅い）

## 2. 候補抽選とビルド

- [ ] COMMONが中心に出て、補助ビルドを考える余地がある
- [ ] RAREのメイン能力を早く引けた時に嬉しい
- [ ] RAREが来なくても「取れないと遊べない」感はない
- [ ] メイン2枠・補助3枠の制限が、何を捨てるか考える面白さになっている
- [ ] 補助3枠が埋まった後、未取得の補助能力が候補から出ない
- [ ] 取得済み補助は、枠が埋まってもLvアップ候補に出る
- [ ] XP吸引を取ると、近くのコインとXPオーブがプレイヤーへ目に見えて吸い込まれる
- [ ] 吸引は遠方でゆっくり始まり、近づくほど速くなって自然に回収される
- [ ] 前方のアイテムは遠くから逆走せず、体の近くで自然に回収される
- [ ] 吸引Lvが高いほど、高所のXPオーブを無理なく回収できて気持ちいい
- [ ] 実際に「かなり高い」コイン・XPオーブが出現し、吸引Lvの差を体感できる

記録: 印象に残ったビルド / 欲しかったのに取れなかった能力

## 3. レジェンド

- [ ] LEGENDがレアすぎず、出た時に特別感がある
- [ ] デスイーターのLv6が、スコア特化のご褒美として分かりやすい
- [ ] スロット解放でメイン3種を揃える価値がある
- [ ] 修羅完成ビルド（3段・滑空＋コイン系3種）で10Kを測り、速さ・死亡リスクと1.30xが釣り合う
- [ ] 変換器はコインを失う不満より、XPが伸びる快感が上回る
- [ ] ギャンブラー完成ビルド（3段・滑空＋コイン倍率・コンボ持続・XP倍率）で10Kを測り、止まらない手軽さと1.05xが「考えたビルドより少し弱い」位置に収まる

記録: 出現距離 / 取得したLEGEND / 良かった・悪かった点

## 4. 終盤と報酬

- [x] ビルド完成後にLEVEL UP画面が出ず、走行が止まらない
- [x] `Lucky!`報酬が分かりやすく、XP系能力を取る意味が残る
- [x] `スコア完成ビルド`と`変換器完成ビルド`を同じ距離から試して、どちらも伸ばす理由がある
- [x] 変換器ではCONVERT XPが増え、コイン得点がゼロでもLucky!の回数と合計スコアを比較できる
- [x] 変換器完成後、変換XPがBANKへ貯まり、次の`SOUL LUCKY!`で大きく得点化される
- [x] 完成後の必要XPが増え続けず、XP特化ビルドに報酬機会が残る
- [x] `10K比較を開始`から10,000m後に結果が確定し、`10K結果をコピー`で増分を共有できる
- [ ] 100,000m以降でも毎回同じ完成ビルドになりすぎない
- [ ] 200,000m級でも、能力選択とスコア狙いの差が残る

記録: 完成時の距離 / Lucky!の体感（弱い・適正・強い） / SCORE完成・変換器完成の10K比較結果

## 5. 既知修正点の確認

- [ ] ゲームオーバー時、XPバーと全能力アイコンが残らない
- [ ] ライバル登場・デスイーター降臨・Lucky!などの通知がXPバーと重ならない
- [ ] メイン3枠＋補助3枠＋LEGEND1枠でも、HUD内のアイコンが重ならない
- [ ] PCでHUDやLEVEL UPカードが小さすぎない
- [ ] 携帯でLEVEL UPの3カードとHUDが画面内に収まる

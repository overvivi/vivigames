## 全員共通の選択画面規格

- 表記順は `番号 → マーク → 名前 → 肩書き`。
- 通常立ち絵は正面、足幅を肩幅より狭くする。
- 選択立ち絵は腕を振らず、脚だけで前に踏み出し始める。ゲートから出てくる一歩目として読ませる。
- 全員の足元・頭位置・カメラ距離は共通基準。身長差は小柄寄りから最大級までの範囲だけに留め、等身や撮影距離で別作品のキャラに見せない。
- 立ち絵は透明素材のみ。ゲート内背景、フレーム、文字、街並みを焼き込まない。
- 7人は同じアクションゲームに登場するキャラクターとして、全員を**陰影・線密度・素材感が揃ったダーク寄りのゲーム用コンセプトアート調**で描く。ポップなアニメ調／絵本調／実写調へ個別に振れない。
- RAVEN／KIRI／VIVIの試作で得られた、陰影のあるスタイライズドな質感を全員の共通基準とする。TΩ9も「リアルな野生動物」にしないだけで、丸いポップキャラにせず、同じ画風の信楽焼モチーフの戦闘キャラクターとして扱う。
- 手持ち武器は、**手のひらと四本の指で柄を自然に握り、鍔の直下に手が来る**ことを採用条件にする。刃・鍔・柄尻を掴む／武器が手を貫く／手首が不自然に折れる持ち方は不採用。RAVENとBRICKは片手だけで持ち、反対の手は空にする。利き手で不自然になる場合は左右を入れ替えてよい。

## 次回の制作順（ユーザー確定）

1. 肩書きは維持したまま、7人それぞれの種族・体格・顔・髪・服・装備・戦い方を具体的に確定する。必要なら既存案とまったく異なる種族へ再設計してよい。
2. 確定設定をもとに、セレクト用の通常待機／選択時の一歩目を制作する。写真風・実写風にもポップなアニメ調にも寄せず、ダーク寄りの統一されたゲーム用コンセプトアートとして制作する。
3. 同一キャラの2枚は、顔・髪・衣装・装備・体格から**85%以上同一人物だと判断できること**を採用条件にする。特にTΩ9のように別人へ見える組み合わせは採用せず、次の工程へ進まない。
4. 14枚の立ち絵が確定してから、そのデザインを正本として戦闘用のちびキャラ／待機・攻撃・勝敗・攻撃エフェクトを一新する。立ち絵と戦闘素材を別々の見た目で作らない。

現在の14枚は、構図・透明化・ゲート内への収まりを検証するための試作として扱い、最終キャラクターデザインの正本にはしない。

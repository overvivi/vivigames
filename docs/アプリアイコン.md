# VIVI GAME BASE アプリアイコン

更新: 2026-09-22。ホーム画面・ブラウザ用アイコンを追加。正式サイト名は変更していない。

## 採用デザインと参照元

黒いスケルトンのゲームカセット、シアンの大きなピクセルV、マゼンタの縁光、金色の接点。
ポータルの「秘密基地でカセットを選び、1台の携帯機へ挿す」という体験を象徴する。
特定作品の主人公やゲーム画面に寄せず、複数のゲームを収録するサイト全体の印にした。

- サイトの正式ロゴは `index.html` のCSS文字「VIVI GAME BASE」。画像ロゴ作成の古い仕様書より現行実装を優先。
- 既存素材 `images/portal/console-body.webp` をスケルトン材質の参考に使用。
- 既存素材 `images/portal/arcade-bg-desktop.webp` を秘密基地・カセット・配色の参考に使用。
- カセットの段差形状は現行ポータルのCSSカセットと揃え、Vはブランド名とピクセル書体から採用。
- 収録作はランナー、2048、論理パズル、対戦、リズム、弓、レースなど多様で、共通の正式キャラクターはない。
- 元画像の流用・拡大ではなく、上記2枚を参照画像として組み込み画像生成機能で新規制作。

## 保存ファイルと再生成

| ファイル | 寸法・用途 |
|---|---|
| `icons/source/app-icon-1024.png` | 1024×1024、保持するPNGマスター |
| `icons/apple-touch-icon.png` | 180×180、iPhone / iPad |
| `icons/favicon-16x16.png` | 16×16、タブ |
| `icons/favicon-32x32.png` | 32×32、タブ |
| `icons/icon-192.png` | 192×192、Android等 |
| `icons/icon-512.png` | 512×512、Android等 |
| `icons/icon-maskable-512.png` | 512×512、OSの切り抜き用 |
| `favicon.ico` | 16・32・48pxのPNGを収容 |

`node tools/app-icons.mjs` でマスターから全配信用画像を再出力する。既存のsharp依存を利用。
マスターは生成原画1254pxを1024pxへ縮小したもの。角丸は画像に焼き込まず、すべて不透明。
maskable版だけはマスターを352pxに縮小して512pxの中央へ配置する。
[W3Cのsafe zone](https://www.w3.org/TR/appmanifest/#icon-masks)（半径40%の円）内にカセット・V・接点を収める。
[Appleの指定方式](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)に従い `apple-touch-icon` を指定する。

## 組み込み

`index.html` のheadに各リンクを追加。`site.webmanifest` は正式名 `VIVI GAME BASE`、
短縮名 `VIVI BASE`、開始URLとscopeとidを `./` に設定。
アイコン参照も相対URLなのでGitHub Pagesの `/vivigames/` を維持する。
ホーム画面からはstandalone表示を希望するが、画面方向は固定しない。
`?v=20260922` をHTMLとmanifest内の画像参照に共通指定。差替時は両方更新する。
既存の共通favicon・manifest・Service Workerはなかった。Service Workerやオフライン機能は追加していない。
ゲームHTML、ゲームロジック、セーブ、ランキング、API、DB、既存トップページの見た目は変更しない。

## 検証

- アイコン出力処理成功。ポータルは静的HTMLのため、別のアプリビルド工程はない。
- `npm run verify`: 14ファイル / 35インラインスクリプトの構文・構造・素材参照OK。
- `npm run test:unit`: 96件成功（新規アイコン検査4件を含む）。
- `npm run test:hex`: 108件成功。
- Playwright: 既存ポータル12件＋アイコンHTTP検査1件、計13件成功。作業中のトップページと、今回だけを反映する公開対象のトップページの両方で確認。
- 新規検査は全PNGの復号・寸法・不透明度、ICO内の各画像、maskableの発光部の安全円、HTML/manifest参照とルート・サブパス解決を確認。
- 実画面で16/32/60/96/180px、暗い背景・明るい背景、円形・角丸・最小安全円の切り抜きを確認。
- iPhone / Android実機確認はユーザーが担当。
- 最初のブラウザ検査はサーバーの終了待ちで中断。別プロセスでテスト配信し直した結果を成功記録とする（中断ログは上書きしない）。

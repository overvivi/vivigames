## 2026-09-01: 大型召喚ゲート構成（制作前の基準座標）

細い7本の縦ゲートへ全身を押し込む方式は不採用とする。`941 × 1672`のゲーム基準画面を使い、
上部はロスター選択、下部は選択中の一人を大きく見せる召喚ステージへ分離する。

| 要素 | x / y / w / h（基準px） | 役割 |
| --- | --- | --- |
| タイトル | `x=60, y=64, w=820, h=166` | タイトルの最大安全領域。ロゴ自体は等比で中央へ収め、左右の導線を残す。 |
| ミニゲート列 | `x=88〜850, y=254〜538` | 7人分の選択ボタン。通常幅90、間隔22、選択時だけ上へ12px・1.06倍。人物は入れず、番号／既存マーク／名前／肩書きだけを置く。 |
| 大型召喚ゲート外枠 | `x=84, y=561, w=772, h=790` | 画面横いっぱいに近い主役の門。下側は台座ではなく、床へ続く薄い敷居だけを残す。 |
| 大型ゲート内側（背景用窓） | `x=178, y=660, w=585, h=692` | 各キャラ用の異次元背景7枚を等比で収める領域。内側へ金具・文字・発光装飾を描かない。 |
| 選択キャラ | 接地線`y=1,390`、標準表示高`727` | 異次元背景と門の**前**。横へ多少はみ出してよいが、靴底が内側の床から手前の濡れた床へ踏み出す接点へ乗る。全員1枚の透過立ち絵だけを使う。 |
| 操作案内 | `center=(470, 1,465)` | `SWIPE TO SELECT`。門とCTAの間に置く。 |
| START DUEL | `x=130, y=1,445, w=680, h=170` | 既存CTA。下側57pxだけをデッドスペースとして残す。 |

### レイヤー順（背面 → 前面）

1. 共通の雨の街背景
2. 大型ゲートの内側だけへ収めるキャラ別異次元背景（7種）
3. **透過の大型ゲート外枠**（内側・外側ともalpha=0を保つ）
4. 選択キャラの透過立ち絵（7種）
5. 操作案内とSTART DUEL

大型ゲートは縦長の素材をそのまま置くのではなく、上記の`772 × 790`を先に満たす横に強い構図で作る。
装飾は外側の肩・縦柱・上アーチへ集約し、下側は薄い敷居だけにする。内側の背景窓を汚さない。

### 大型門の7種意匠（v2）

外寸・透明開口・敷居の薄さは共通とし、選択中のキャラに合わせて外枠だけを切り替える。門そのものへキャラや武器を描かず、立ち絵と異次元背景の主役性を残す。

## 原画キャンバス

| 状態 | 原画サイズ | 比率 | 共通の床接地線 | 人物の標準高さ |
| --- | ---: | ---: | ---: | ---: |
| 通常ゲート | 600 × 3600 | 1:6 | Y=3,180 | 2,520px（70%） |
| 選択中ゲート | 900 × 3600 | 1:4 | Y=3,180 | 2,520px（70%） |

- 靴底／ローラー／接地点は必ず **Y=3,180**。濡れた地面と反射はここから下だけへ続ける。
- 頭頂の基準はY=660。身長150cmのBRICKは最大120px下げ、180cmのKIRI・TΩ9は最大160px上げてもよい。
- これは身長差ではなく、同じ焦点距離で立った際の自然な差の範囲。頭身や顔サイズを変えて別作品のキャラに見せない。
- 顔・胸・武器／拳の主情報は中央の横60%以内へ置く。左右8%と上下5〜8%は安全余白として扱う。

## 状態ごとの固定構図

- 通常: 正面を向く静かな待機。足幅は肩幅より狭くし、人物の横幅はキャンバスの45〜58%。上から下まで同一のカメラ距離。
- 選択中: 腕を振らず、片脚だけを前へ出した「ゲートから抜け出す一歩目」。顔の大きさ、足位置、カメラ距離は通常と同じ基準にする。
- 選択中は「正面用に描き直した絵」であり、通常版を拡大・回転・トリミングして作らない。

## 共通世界観

- 雨の夜の同一日本風ネオン都市、濡れた黒い路面、薄い霧、正面〜斜め前からの照明。
- キャラ固有色は人物と足元の淡い反射へ使う。背景全体をキャラ色で塗り替えない。
- 枠、名前、番号、読める文字、ロゴ、UIは素材へ描かない。

## 採用判定

1. **生成時点で実アルファを持つこと。** 四隅・外周に完全透明画素（alpha=0）があり、格子・単色背景・発光の背景を後処理で抜いた素材は不採用とする。
2. 固定の実寸ゲート枠に **等倍（縦横比維持）** で配置できること。
3. 接地点が全員同じ床線へ乗ること。
4. 顔サイズ・頭身・人物占有率が基準範囲内であること。
5. 同じ状態の7人を横に並べ、線密度、陰影、肌・布・金属の質感、カメラ距離が**90%以上同じゲームのロスター**と判断できること。1人でも写真風・POPアニメ風・ダークファンタジー風へ外れたら全体を再生成する。
6. 各キャラの通常／選択を並べ、顔、髪、体格、衣装、装備、種族要素が**85%以上同一人物**と判断できること。片脚だけ前に出す以外の差（別顔、別衣装、別武器、別頭身）は不合格とする。

不合格なら、その素材は変形せず新規生成する。

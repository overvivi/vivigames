# ポータル背景画像の仕様（秘密基地）

`index.html` のヒーロー（一番上の大きな帯）に敷く背景を、
**ゲームセンターの店内** から **秘密基地** へ作り替える。

## なぜ変えるか

ゲーム置き場を「筐体を並べる形」から「1台の実機にカセットを挿す形」へ変えた。
店内の写真は**筐体が並んでいる前提の絵**で、実機1台とは噛み合わない。
「INSERT COIN」「GAME FLOOR」も、コイン投入口と店の床があってこその言葉だった。
文言は既に差し替え済み（`SELECT YOUR GAME` / `CARTRIDGES`）。

## 発注する画像

| ファイル | サイズ | 用途 |
|---|---|---|
| `arcade-bg-desktop.webp` | 2560 × 1440 | PC・タブレット |
| `arcade-bg-mobile.webp` | 1080 × 1920 | 携帯（**縦長**） |

**同じ場所を、横位置と縦位置で撮り直した2枚**として作る。
別々の部屋に見えると、画面幅で切り替わったときに違和感が出る。

原本はPNGで受け取り、webp変換は `npm run portal:images` で行う
（`tools/portal-images.mjs` の TARGETS へ2行足す）。

## 描くもの

**個人の秘密基地。カセットが壁一面に並んでいる部屋。**

- 地下か廃ビルの一室。生活感より**設備の密度**を出す
- **壁一面のカセット棚**。透明な樹脂のカセットが整然と並び、
  それぞれが淡く発光している。これが主役
- 作業机、モニター、配線、工具、点いたままの端末
- 光源は少なく、**カセットの発光とモニターの明かりだけ**が空間を照らす
- 色はシアン(#20e6ff)とマゼンタ(#ff2ba6)を差し色に、全体は暗い青緑〜黒

### 絶対条件

1. **中央から下が暗く、平坦であること**
   → ここへサイトのロゴと文字を重ねる。模様や明るいものを置かない
2. **人物を描かない**
3. **文字・数字・ロゴを描かない**
4. **全体が暗いこと。** 明るい絵だと上に載せる文字が読めない
5. 縦横比を守る（PC 16:9 / 携帯 9:16）

### 指示文（PC版・そのまま貼れる）

```
個人の秘密基地を描いてください。2560×1440ピクセル、横位置。

場所:
・地下または廃ビルの一室を、部屋の中ほどから見た構図
・生活感は薄く、設備の密度が高い空間

必ず入れる要素:
・壁一面のカセット棚。透明な樹脂製のゲームカセットが整然と並び、
　一本ずつが淡く発光している。これが画面の主役
・作業机、複数のモニター、床や壁を這う配線、工具、点いたままの端末

光と色:
・光源は少なく、カセットの発光とモニターの明かりだけが空間を照らす
・シアン(#20e6ff)とマゼンタ(#ff2ba6)を差し色にする
・全体は暗い青緑から黒。明るくしないこと

絶対に守る条件:
・画面の中央から下は暗く平坦にする。そこに文字を重ねるので、
　模様や明るいもの、目立つ物体を置かない
・人物を一切描かない
・文字、数字、ロゴ、看板の類を一切描かない

写実的な3DCG風。奥行きのある構図。
```

### 指示文（携帯版）

上の指示文の冒頭だけ差し替える。

```
1080×1920ピクセル、縦位置。同じ部屋を縦向きの構図で描いてください。
壁のカセット棚が画面の上半分に来るようにし、下半分は暗く平坦にする。
```

### 受け取り時の確認

- [ ] 中央から下が暗く平坦か（ここに文字が乗る）
- [ ] 人物が写り込んでいないか
- [ ] 文字や看板が入っていないか
- [ ] 全体が暗いか（明るいと文字が読めない）
- [ ] PC版と携帯版が**同じ部屋に見えるか**
- [ ] 縦横比が合っているか

## 差し替え後の作業

1. 原本を `images/portal/source/` へ置く
2. `tools/portal-images.mjs` の TARGETS へ2行足して `npm run portal:images`
3. `npm run test:portal` で表示を確認

ファイル名は変えないので、CSSの書き換えは不要。

## 生成AIがよく外すところ

| 外れること | どうなるか |
|---|---|
| 「文字を描かない」 | 棚や壁に勝手に看板や型番を書く |
| 「暗く」 | 明るい照明を足してきて、上に載せる文字が読めなくなる |
| 「下半分を平坦に」 | 手前に机や物を置いてしまい、ロゴと重なる |
| 「人物を描かない」 | 椅子に座った人影を入れてくる |
| 縦横比 | 携帯版を横位置で出してくる |

# ポータル筐体画像の仕様（HEXAMINE用）

`index.html` のゲーム置き場は、ゲームごとにアーケード筐体の画像を並べている。
HEXAMINEを載せるには **3枚** 必要。既存の2本（HELL RUNNER / 討伐2048）と
**同じ筐体の型** で色だけ変えるのが前提。

素材は `images/portal/` に置く。生成した元PNGは `images/portal/source/` に残す。

## 必要な3枚

| ファイル名 | サイズ | 中身 |
|---|---|---|
| `cabinet-hexamine.webp` | 1200 × 1680 | 筐体本体。背景は透過 |
| `title-hexamine.webp` | 1024 × 192 | 「HEXAMINE」のロゴ文字。背景は透過 |
| `play-button-hexamine.webp` | 1024 × 256 | PLAYボタン。背景は透過 |

**3枚とも背景は必ず透過**。ポータル側で重ねて配置するため、
背景色が入っていると四角い板が浮いて見える。

生成はPNGで受け取り、こちらでwebpへ変換する（PNGのまま渡してくれれば良い）。

## HEXAMINEの色

| 用途 | 色 |
|---|---|
| 主色 | シアン `#20e6ff` |
| 差し色 | マゼンタ `#ff2ba6` |
| 地の色 | ほぼ黒 `#05070d` |

討伐2048が紫、HELL RUNNERが赤系なので、**シアンで並べたときに区別がつく**。

## 1. 筐体（1200 × 1680）

既存の `images/portal/cabinet-boss-2048.webp` と **同じ型の筐体**。
違うのは「発光色」と「画面に映っている絵」だけ。

守ること:

- 正面から見た縦長のアーケード筐体。**背景は完全透過**
- 上のマーキー（看板部分）は **文字を入れず、暗いままの空白にする**
  （ロゴは別画像をポータル側で重ねるため。ここに文字を描くと二重になる）
- 側面のふち・ジョイスティックの玉・4つのボタン・画面のふちが **シアンに発光**
- 本体は黒〜濃紺の金属質。傷や汚れの質感あり
- 下部にコイン投入口とコインドアがある（既存と同じ）
- 筐体の足まで含めて全体が収まること。見切れさせない

画面に映す絵（キーアート）:

> 六角形のマスが敷き詰められたパズル盤面。
> いくつかのマスがシアンに光り（＝原子）、残りは黒く沈んでいる。
> 黒いマスには数字がうっすら浮かぶ。
> 盤面の奥に、六角形が結びついた分子構造の模式図がぼんやり光っている。
> 全体に暗く、シアンの発光だけが強い。

## 2. タイトルロゴ（1024 × 192）

- **背景は完全透過**
- 中央に横書きで `HEXAMINE`
- 文字は白〜ごく淡いシアン。**輪郭のまわりにシアンのネオンが滲む**
- 太めのサンセリフ体。文字間はやや広め
- 上下左右に少し余白を取る（端に接触させない）

既存の `title-boss-2048.webp` と同じ作り。あちらは紫のネオンなので、
**光の色をシアンに変えただけ** のものを想定している。

### 指示文

```
1024×192ピクセル、背景は完全透過（PNG）。
中央に「HEXAMINE」と横書きで配置してください。

・太めのサンセリフ体、大文字、文字間はやや広め
・文字の色は白〜ごく淡いシアン
・文字の輪郭のまわりにシアン(#20e6ff)のネオンが柔らかく滲む
・上下左右に余白を取り、文字が端に接触しないようにする
・文字以外は何も描かない
```

## 3. PLAYボタン（1024 × 256）

- **背景は完全透過**
- 角の丸い横長の長方形。中は暗い色（ほぼ黒）で塗る
- 枠線が **シアンに発光**（二重の線に見える作り）
- 中央に白で `PLAY`

### 指示文

```
1024×256ピクセル、背景は完全透過（PNG）。

角丸の横長ボタンを描いてください。
・中は暗い色（#0d0f18程度）で塗りつぶす
・外周の枠線がシアン(#20e6ff)に発光している。枠は二重線に見える作り
・中央に白い太字で「PLAY」と横書き
・ボタンの外側には何も描かない
```

## 画像が揃ったあとの作業（こちら側）

1. PNG → webp へ変換して `images/portal/` へ配置
2. `index.html` に筐体を1つ追加する
3. **COMING SOONの筐体はグリッドの4つ目へ移す**

いま筐体は2つ横並びで、COMING SOONだけがその下に単独で置かれている。
HEXAMINEを足すと2列グリッドが「2つ＋1つ」の欠けた形になるので、
COMING SOONをグリッドの中へ入れて **2×2** にする。
COMING SOONは消さない（次のゲーム枠として残す）。

```
いま                    追加後
┌──────┬──────┐        ┌──────┬──────┐
│ HELL │ BOSS │        │ HELL │ BOSS │
└──────┴──────┘        ├──────┼──────┤
   ┌──────┐            │ HEXA │ COMING│
   │COMING│            └──────┴──────┘
   └──────┘
```

4. 筐体ごとにロゴとPLAYボタンの位置を微調整する変数（`--title-x` 等）を足す
5. パッチノートに追記
6. `npm run verify` で素材の参照漏れを検査

## 注意

- 生成AIは指示しても背景を透過にしないことがある。**必ず透過を確認する**
- マーキーに勝手に文字を入れてくることが多い。**空白のままか確認する**
- サイズが違っても後で調整できるが、**縦横比は合わせる**（筐体は5:7）

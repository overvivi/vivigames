# HELL RUNNER 2 引き継ぎ

最終更新: 2026-08-20

## 作業対象と絶対条件

- 実装対象は `games/hell-runner-2.html` のみ。`games/temple-run-clone.html`（HELL RUNNER 1）は凍結済みで触らない
- 画像素材は `images/hell-runner-2/` に分離済み。既存のコイン、オーブ、能力アイコン、カード枠は利用可能
- 巨大HTMLにはbase64行があるため、全体読み・全体整形は禁止。対象周辺だけを読んで `apply_patch` で部分編集する
- 開発URLは `games/hell-runner-2.html?debug=1`。本メモ作成時点でローカルのデバッグサーバーは停止済み

## 今できていること

### ローグライトの基本

- 開始時は2段ジャンプのみ。ラン中XPでLEVEL UPし、メイン2枠・補助3枠・LEGEND1枠を組む
- メイン: 3段ジャンプ / 滑空 / 転生。3段ジャンプと滑空はLv3まで、転生はLv1固定。補助: コイン倍率 / コインコンボ / コンボ持続 / 経験値倍率 / 経験値吸引
- 3段ジャンプはLv1で旧性能の70%の3回目を解放、Lv2で85%、Lv3で既存能力と同じ100%へ到達する。滑空はLv1の重力0.65倍→Lv2で0.47倍→Lv3で既存能力と同じ0.32倍へ到達する。1・2段目の操作感は変えない
- LEGEND: デスイーター / スロット解放 / 修羅 / 変換器 / ギャンブラー
- レジェンド抽選率の本番初期値は35%（平均で約3回に1回）。一度でもLEGEND候補を見たが取得しなかった時は、以後35%を維持する。通常抽選で早期取得の運を残しつつ、90,000mまで未取得なら最初の安全な着地でLEGEND候補を必ず1枚出すため、100,000mまでには必ず一度はLEGENDへ触れられる。初回・再出現率は開発者ツールで1〜100%に変更できる
- LEVEL UPの各候補カード下には、小さな`⟳`を表示する。カードごとにそのLEVEL UP中1回だけ、同ティアの未提示能力へ引き直せる（LEGEND→別LEGEND、RARE→別RARE、COMMON→別COMMON）。無限に欲しい能力を探せないよう、使用後はそのカードの`⟳`を消す
- 通知の確定初期値はサイズ1.40x、X=51%、Y=264px。ライバル、デスイーター、GAMBLE、RANDOM GET、Lucky、SOUL LUCKY、LEGEND CALLだけが共通通知に出る。転生後の「復活！」通知は出さない
- LEVEL UP下部の能力欄は、上部HUDと同じ現在ビルド・能力Lvをメイン→補助→LEGENDの順で表示する
- LEGEND「デスイーター」取得時だけ、死神が追従する。上方向のアイテム吸引・取得範囲は+210px、横方向は拡大しない
- XP満タンが空中だった場合、次の着地までLEVEL UPを保留する
- 通常の能力選択後は0.65秒だけ再開猶予。ギャンブラーとLucky!報酬は停止しない

### 収集物と高所報酬

- コイン、XPオーブは画像素材化済み。重複を抑え、単体・3連・ピラミッドは56pxグリッドで統一
- 高所アイテムは奈落上だけに出る。1層目は常時、2層目は20,000m以降、3層目は60,000m以降
- 現在の初期値: サイズ2.20x / 発光1.80x / 高所高さ1.50x / コイン40% / オーブ20% / 複数オーブ5% / 高所コイン40% / 高所オーブ20% / グリッド56px
- XPオーブを取るたび、XPバーと右側XP数値が即時更新される

### LEGEND待ちとLucky!報酬

- メイン・補助枠を埋めた後、LEGEND抽選に外れたXP到達はLEVEL UPを出さず、Lucky!コイン報酬になる
- LEGENDだけが候補に出た時は「今回は見送る」を出す。見送ってもLucky!コイン報酬になるため、欲しいLEGENDを待ちながらスコアを狙える
- 通常能力が候補に残る間は見送りボタンを出さない
- Lucky!の基礎報酬は18 / 28 / 46。コイン価値と変換器を含む最終バランスは未確定
- 完成後は必要XPを最大800で頭打ちにする。育成中の必要XP増加は維持し、完成後にXP特化ビルドの報酬機会だけが消えないようにする
- 変換器中のコインはXPだけへ変換され、コインコンボ・コイン倍率・コンボUIには一切反映しない。取得時に既存コンボも`00`へリセットする
- 変換器で完成後に得た変換XPは魂BANKへ貯まり、次のLucky!で`変換XP × 5.20点`を基礎報酬へ加算して`SOUL LUCKY!`として得点化する。完成前の変換XPはビルド速度だけに使う
- 変換器取得中だけ、XPバー下に`SOUL BANK` HUDを表示する。透過の魔導瓶枠`images/hell-runner-2/ui/soul-bank-vessel.png`の内側を変換XPで満たし、80%近くで発光、満タンでは瓶口から魂が漏れる。SOUL LUCKY!時は瓶が光って揺れ、放射状の割れフラッシュ後に空へ戻る。生成原本は`source/ui/`に保管
- 変換器中はCOIN COMBOを表示しない。SOUL BANKはコンボと同じX/Y領域を使うため、HUDを増やさず置き換わる。瓶の魂火は素材中心の空洞（幅20px相当・高さ34px相当）にだけ収め、`SOUL BANK`と数値は能力アイコンと干渉しない瓶の下へ置く

### コンボ表示

- コンボパネルはプレイ中に常時表示する。コンボが切れている時は`00`・ゲージ空、連続取得中は連番と発光を強める
- 外装は使わず、大きい連番、現在得点倍率、下部の残り時間ゲージだけで構成する。色は青（0）→緑（2〜4）→金（5〜7）→赤紫（8〜）へ変化し、8〜では連番だけを流れる虹色にする（倍率とゲージは赤紫のまま）
- `?debug=1` の `コンボ表示を確認` で、実際のコイン列を待たずにx8表示を出せる
- 確定初期値: 基本持続3.00秒、コンボ表示X84% / Y22%、コンボ・ゲージ倍率1.00x、ゲージX/Y 0px
- 開発者ツールで次を個別調整でき、`ローグライト値をコピー`に値も含まれる
  - コンボ表示サイズ / X / Y
  - コンボゲージ幅 / X / Y
  - 基本コンボ持続時間

### デバッグ機能

- 距離移動は取得済みビルド、能力Lv、XP進行、ラン統計を保持する。古いLEVEL UP表示だけを閉じる
- `スコア完成ビルド`はスロット解放＋3段ジャンプ・滑空Lv3＋転生＋コイン倍率・コンボ・持続Lv5の完成状態、`変換器完成ビルド`は変換器＋3段ジャンプ・滑空Lv3＋経験値倍率・吸引・持続Lv5を即時セットする。`修羅完成ビルド`は3段ジャンプ・滑空Lv3＋コイン倍率・コンボ・持続Lv5、`ギャンブラー完成ビルド`は3段ジャンプ・滑空Lv3＋コイン倍率・コンボ持続・経験値倍率Lv5をセットする。全プリセットは次のXPを取るだけでLucky!を確認でき、その後の必要XPは完成レベル相当の終盤値へ戻る
- ラン統計は距離、合計スコア、通常コイン、Lucky!、通常オーブXP、変換器XPを分けて表示する。2ビルドの得点と完成速度を比較するための表示
- `10K比較を開始`は現在地の数値を記録し、10,000m後に増分SCORE / COIN / Lucky! / ORB XP / CONVERT XPを確定表示する。`10K結果をコピー`で送付用の1行を取得でき、途中の地点移動では比較を破棄する
- 同条件比較用に開発者ツールの地点移動へ`100K`を追加。スコア完成・変換器完成は必ず同じ100K開始で比較する
- 100K帯10K比較の確定候補: スコア完成`+14,110`（COIN +4,064 / Lucky +46）、変換器完成`+13,850`（Lucky +92 / SOUL +3,758）。差は約1.8%で、完成後XP上限800・魂換金5.20点/XPを初期採用する
- 修羅・ギャンブラーの倍率は、**取得後**の総スコア（距離＋コイン＋Lucky!）へ掛ける。取得前の距離へ遡及しないため、終盤で取った瞬間に過去のスコアだけが跳ねない。修羅は固定1120px/sで高リスクの`1.30x`。ギャンブラーは選択不要・ビルド最適化不可の代償として`0.85 / 0.90 / 0.95 / 1.00 / 1.05x`を均等抽選し、平均`0.95x`にする。取得時の`GAMBLE! SCORE x...`と10K結果で確定値を確認でき、開発者ツールでは最高値を調整・コピー可能
- 100K帯10K比較（修正後）: 修羅完成`+17,032`（COIN +3,083 / Lucky +18）、ギャンブラー完成`+13,643`（COIN +2,975 / Lucky +18）。修羅はスコア完成より約20.7%高く、早期取得時の大化け枠として妥当。ギャンブラーはスコア完成より約3.3%低く、選択を捨てる代償として「少し弱い」位置に収まった
- 開発者ツールでは、完成後XP上限（初期800XP）と魂換金レート（初期5.20点/XP）を個別に調整・コピーできる
- WALL TEST、NO FALL、各収集物の密度・サイズ・高さ・間隔、レジェンド率、Lucky!報酬、コイン価値を調整可能
- LEVEL UP時は携帯の開発者ツールを自動で畳み、カードや「今回は見送る」を覆わない
- 携帯のDEV TOOLSは`+`で展開後、パネル内を縦スワイプできる。PCの左側に出すローグライト調整も、携帯では同じパネルの末尾へ統合する
- ゲームオーバー画面は結果の最上部から開き、ランキング登録が出た場合も画面内を縦スワイプしてSIGN UP・RETRYまで到達できる
- 携帯のゲームオーバーは、新記録時だけSIGN UP込みで1画面に収める専用密度へ切り替える。通常終了は従来のゆとりあるロゴ・余白・ボタンサイズを維持し、万一さらに低い表示領域で収まらない場合だけ縦スワイプへフォールバックする
- LEVEL UPの引き直し`↻`は、`C`に見えない矢印形状にし、カードの高さを変えず40×24px・シアン発光の押しやすい表示にする

# よるのリズム便 v0.3

夜のおしごとを題材にした、オリジナルのブラウザリズムゲーム7ステージと3つの別シフト（全10コース）。画像・音源ロジックをすべて `index.html` に含み、HTMLを直接開いても遊べる。インターネット接続やビルドはプレイに不要。

## 遊び方

- 夜ふかし郵便局：木の合図「コン、カン」のあと、1拍待ってタップ。途中から2連続の注文も来る。
- 雲のソーダ屋：2つの合図のあと長押し。2拍、または3拍たったら指を離す。3拍注文は最初の音が高い2音になる。
- 月面おそうじ隊：4拍のお手本を聴き、次の4拍で同じリズムをタップ。
- 真夜中のリミックス：第4ステージ。136 BPM・約62秒・24フレーズ・65判定で上記3操作が交代。判子は2連打、月面は裏拍を含む4〜5打、ソーダは1/2/3拍保持。後半は4拍単位の切替が増える。交代1拍前に専用の音と予告表示、交代時に背景・効果音・操作説明が変わる。練習も全操作と1拍保持を含む。月面の途中で一時停止した場合はお手本から入り直す。

各本番は約1分。練習はお手本付き。マウス・タッチ・Spaceキーで操作。判定は±135ms以内、ぴったりは±52ms以内。押す・離すを個別に判定し、早離し・空押し・無入力も採点する。連打で得点を稼げない。

- 星降る花火工房：合図から長押し、2/3/4拍を数えて離す。成功で夜空に花火、最後は大輪。
- おばけ写真館：低い「はい」風の音、高い「チーズ」風の音の1拍後にタップ。合図の間が0.5拍単位で変わる。成功で記念写真。
- 星のパン屋：4拍のこねるお手本、次の4拍でまねっこ。フレーズ開始から7拍たった合図で長押し、2/3拍で離す。1フレーズ12拍。成功でパンと湯気。
- 別シフト：最初の3ステージの説明画面のボタンから。朝の速達便（128 BPM/2連打中心）、閉店前ラッシュ（124 BPM/1・2・3拍保持）、流星群のおそうじ（130 BPM/裏拍の4打）。速度だけでなく譜面と編曲も変わり、練習・ベスト・切手が独立。

## 見せ場と切手帳

全ステージの最後2フレーズはラストスパート、最後の成功では紙吹雪。郵便局は通常配達→最後6フレーズの連続注文→大きな荷物に1回押し。5コンボから小さな相棒が踊り、ソーダは虹色、月面は成功に応じて星が増える。ミス時は鼻の判子・泡のひげなどの小さな笑いを添える。

リミックスはフレーズ16〜18で伴奏を消し、フレーズ19から全楽器を戻す。音の合図は残すので、初見でも操作内容を聴き取れる。拍と合図のヒントは設定でOFFにできる。

切手は各コース3枚、合計30枚。65点で初クリア、85点、ノーミス（全音成功かつ空押しゼロ）。練習では獲得しない。切手を集めるとメニューの街の家に灯りがともる。旧ベストからクリア/85点切手を移行するが、旧スコア100だけでノーミスだったとは推定しない。設定・ベスト・切手の読み込みは独立し、設定が壊れてもベストを失わない。

一時停止、別タブ、入力中断時は演奏を停止。再開時は現在のフレーズを巻き戻し、4拍の合図から入り直す。音量、±250msの入力補正、16回タップによる補正測定、ヒント切替、端末内のベスト保存に対応。

## 音・絵

7ステージ＋別シフトの伴奏・合図・成功音・失敗音・終演音はWeb Audioによる独自合成。郵便局は軽いスウィング、ソーダは跳ねるポップ、月面は浮遊感、花火は低い太鼓、写真館は揺れる和音、パン屋は温かい跳ねる旋律。写真館の掛け声は声を模した倍音合成で、録音や非同期TTSは使わない。リミックスは共通コードで伴奏をつなぐ。合図と伴奏を別バスに分け、音声クロック基準で先行予約。出力タイムスタンプが利用できる環境では実際の出力時刻を判定へ反映する。

背景は内蔵imagegenで制作した絵本風の6枚。`source/art/` に生成原本、`assets/` に同解像度のWebPを保存。追加3枚は `fireworks.png`（レッサーパンダ）、`ghost.png`（小さなおばけ）、`bakery.png`（くま）。正確な追加生成プロンプトは `source/art/PROMPTS-v03.md`。郵便物・判子・ソーダ・掃除の光・花火・写真・生地・相棒の踊りはCanvasで動く。既存作品の音楽・絵・キャラクターは使用していない。

## 開発・検証

リポジトリ直下から実行：

```powershell
node projects/night-rhythm/build.cjs
node projects/night-rhythm/check.cjs
node projects/night-rhythm/check-flow.cjs
npm run verify
```

編集するのは `source/shell.html`、`style.css`、`core.js`、`audio.js`、`app.js`。生成済み `index.html` の長い画像行は直接編集しない。画像を更新した時だけ `prepare-assets.cjs` でWebPを再生成する。

ブラウザではPCと390×844、新3ゲームの起動・練習・イラスト・別シフト選択・切手帳を確認。全10コースの正解演奏・採点・長押し・音色の切替・保存・切手・旧記録移行・再開・キー入力・補正は決定的な時刻を使ったイベント接続検査で確認。伴奏なしの区間は音声予約ゼロ、それ以外の全小節は伴奏ありを検査。実iPhone/Androidの音声遅延と触り心地は実機調整対象。

ローカル確認URL：`http://127.0.0.1:5199/projects/night-rhythm/index.html`。同じLANの携帯からは、起動中のPCのIPv4アドレスとポート5199を指定する。ローカルサーバーが停止していたら `PORT=5199`、`HOST=0.0.0.0` の環境変数で `node tests/static-server.cjs` を起動する。

## 画像制作指示の記録

共通：3:2の横長、和製絵本をイメージした平面ガッシュ、紙の粒子、太く読みやすい輪郭。人物は左1/3で全身、右半分はゲームの動く物体用に静かな空間。文字・ロゴ・UIは描かない。

- 郵便局：夜の郵便局、左の小窓と仕分け棚、蜂蜜色の灯り。クリーム色の犬、コーラルの帽子、青いエプロン、赤い判子。右側は暖かいクリーム色の壁と作業台。
- ソーダ屋：雲の上の屋台、ミントと桃色の空、白いふわふわの猫、青緑のエプロン、丸いソーダマシン。右側は余白のある淡いミントのカウンター。
- 月面：ラベンダーの月面基地、黄色い月の丸窓、クリーム色のうさぎ、クリームの宇宙服と黄色のヘルメット、掃除ブラシ。右側は静かな薄紫の空間。

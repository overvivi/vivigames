# Seraph's Last Stand 仕様調査

2026-09-23。ユーザー所有のSteam版（`D:\SteamLibrary\steamapps\common\Seraph's Last Stand`）から、
`data.unity3d` と英語ローカライズを自前のUnityFS展開器で取り出して確認した。
Unity 2021.3 / IL2CPP。以下は**挙動の読み取り**であり、原文の丸写しではない。

## 1. 弾の相殺 — 単純な相殺ではない

自弾にも敵弾にも「**耐久（resistance）**」がある。ぶつかると耐久を削り合い、尽きた方が消える。

- 自弾の耐久を上げる通常アイテムが存在する（1段階ごとに+1）
- **強い敵の弾ほど耐久が高い**。耐久が足りない自弾は、敵弾を消せずに自分が消える
- 貫通ではなく通過扱い。自弾は敵弾を「抜けて」進む
- そのアセンション（進化）は「敵弾を1つ抜けるたび自弾の威力が+25%」。
  つまり**弾幕が濃いほど自弾が育つ**という逆転が起きる

これが「弾が増えるほど画面が派手になるのに、処理できる」感覚の中核。

## 2. ステージは無い。波だけが延々続く

- `WaveManager` / `WaveCounter` / `StartWaveButton`
- 章・ステージ・エリアの区切りは無く、波が続くだけ
- 「毎波リセット」「毎波で全回復」「5波のクールダウン」など、波が唯一の時間単位
- 波と波の間にカード選択が挟まる

## 3. 敵の構成

`Weak_Melee` / `Weak_Ranged` / `Strong_Melee` / `Strong_Ranged` の4系統に、
`lvl2` `lvl3`（弱・遠は`lvl4`まで）の段階がある。ほかに `AntiAir`、`Boss1` `Boss2`。

つまり**敵の種類を増やすのではなく、同じ系統の上位版に置き換えて硬く・強くしていく**。
見た目の情報量を増やさずに圧を上げる設計。

## 4. 通貨は敵からの低確率ドロップ。コンボは存在しない

- **Soul Orb**：自然ドロップ率 1%。アイテムで +1% ずつ積める
- 用途は**恒久強化の購入**と**杖・帽子の解放**（＝本作の遺灰の祭壇と弔具・仮面に相当）
- **Healing Orb**：敵の死亡時5%（アイテム取得時）。回復量はスタックで増える
- **コンボ／連祷という概念は無い**。スコア倍率も無い

スコアはSteamのリーダーボードに送るだけで、ゲーム内の資源とは無関係。

## 5. カードとアセンション（＝禁忌進化の原型）

- 波クリアごとにカードを選ぶ。レアリティは白（common）／緑（uncommon）／epic
- リロール可能。選択肢を+1するアイテムがある（表示上限10枚）
- **全74アイテムに「アセンション」がある**。「Xを N スタック集める」で解禁される上位効果
- Nは3〜20とばらつく（例：3スタックで解禁されるものから、20スタック必要なものまで）
- **取得数に上限は無い。条件を満たしたものから順に乗る**

ここが本作と決定的に違う。本作は目標にした進化以外が候補から締め出される場合がある。

## 6. 恒久強化（Soul Orbで買う）

`Damage +1` / `Atk. Speed +5%` / `Move Speed +10%` / `Defense +1%` / `Stability +1`

**耐久（Stability）が恒久強化に入っている**のが重要。弾の撃ち合いに勝てるようになる、
という形で「前回の死が次の走りを楽にする」を表現している。

## 7. 杖7種・帽子6種

- 杖：通常／三連／追尾／爆発／氷結／雷／虹
- 帽子：魔法使い／プロペラ（二段跳び、跳躍高さ制御不可）／アンコモン（緑のみ出る）／
  挑戦者（アイテム2倍だが敵も2倍、ランキング対象外）／フェドラ／ヘルメット（防御増・移動減）

**帽子は純粋な強化ではなく、必ず代償がある**。本作の仮面と同じ発想。

## 8. 説明文の量 — 原作の遊び方は3行

```
- Instructions -
1. kill everything.
2. choose a card.
3. leave your mark.
```

これが全部。操作は画面内に `Shoot (Hold)` `Esc - Pause` `Q - Toggle Auto-Attack` のみ。
アイテムの詳細説明は**カードの上ではなく、別途開く用語集側**に置かれている。
カード上は一行の効果だけ。

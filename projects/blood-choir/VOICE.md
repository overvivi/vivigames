# BLOOD CHOIR — 文言の規則

画面の文字は「解説」ではなく「ゲームの一部」として書く。迷ったら短いほうを選ぶ。

## 名乗り
- 正式名称は **BLOOD CHOIR** のみ。「— 血の聖歌」等の副題は付けない。
- 日英の併記をしない。メニュー・ボタンは日本語だけ。
  - 例: ×「墓碑銘 RECORDS」 ○「墓碑銘」
- パネル見出しの英語（`header()` の第1引数）は装飾として残す。ラベルの重複ではないため可。

## 語り
- 世界観の文は **常体**。「〜します」「〜できます」「〜ましょう」を使わない。
  - ×「遺灰で弔具を解放しましょう」 ○「遺灰は弔具に変わる」
- 保存失敗・読込エラーなど**システムの通知だけ**は丁寧語のままでよい。世界の声とUIの声を分ける。
- 語彙は既存の体系を使う: 弔具 / 仮面 / 遺灰 / 祭壇 / 禁書 / 墓碑銘 / 葬送 / 連祷 / 大奇跡 / 主 / 異形。

## 減らす
- 同じことを二度言わない。見出しと本文で内容が重なったら本文を削る。
- **保証の文を書かない。**「通常の記録は変わりません」「影響しません」の類は、疑われて初めて要る文。既定では書かない。
- 数値の算出方法・端数処理・仕様の但し書きはパッチノートであってUIではない。どうしても要るなら一行に畳む。
- 触れば分かることは書かない。詳細は禁書（図鑑）へ逃がす。

## 自己申告をしない
- タイトル画面・ゲーム内に「テスト版」「仮素材」「感想募集中」を置かない。作り手の事情はポータルの更新履歴側に書く。
- 版数（Ver 0.1.0）とレーティング表記（血と異形の表現を含みます）は残してよい。

## 波の表記
- メニュー・パネルは「第8波」。HUD（`#wave-label`）だけ `WAVE 08`。混ぜない。

## 2. 現在の仕様（変更後）

### 2.1 遺灰（通貨）

`data.js` の `D.ASH` 一箇所で調整できる。

```js
ASH:{ chance:.03, drop:1, boss:25, medal:.2, life:32 }
```

- **雑魚**: 撃破時 `chance`（3%）で落とし物を落とす。拾得量 `drop`（1）
- **主（ボス）**: 撃破時に `boss`（25）が確定で入る
- 落とし物は `run.pickups` に入り、**触れて拾う**（磁力の範囲に入れば寄ってくる）
- 生命が満タンでも拾える。回復片は傷ついている時だけ寄る
- **波をまたいで床に残り、`life`（32秒）で朽ちる。** 波の切り替えでは消えない
- 寿命は戦闘中だけ減る。強化の選択中や結果画面では止まる
- 採取（`stats.harvest`）が両方に掛かる
- **記章（実績）の報酬に `medal`（0.2）を掛ける**。素の合計2955 → 591

実測（seed 7、第32波まで）:

```
出現 881 体 / 主 4 体
落とし物 約26 + 主 100 = 約126 遺灰／1クリア
（旧仕様は波クリアごとの固定配給で約244 + 記章2955）
```

全装備の解放に必要な額は 1590 遺灰（弔具820 + 仮面770）。

### 2.2 スコアと連祷 — 廃止

- **得点（score）を一切加算しない。** 記録の保存形式には `score` フィールドが残っているが常に 0。互換のため消していない
- **連祷（コンボ）は廃止。** HUD の表示、倍率、最長記録、結果画面の行をすべて削除
- 墓碑の並び順は **到達波 → 時間** になった（得点を見ない）
- 理由: 武器ごとの連続撃破のしやすさが、そのまま収入差になっていた。原作もコンボを持たない

### 2.3 進化と共鳴 — 目標選択を廃止

- **「追い求める禁忌」「共鳴を目指す」の選択UIを全廃。** 支度画面の select、`guidance-preview`、強化画面の「目指す禁忌：…」、ビルド画面の「この禁忌を目指す」ボタン、共鳴の二段階の導き、3波ごとの材料保証
- `drawChoices()` を作り直した:

```js
// 条件の揃った禁忌進化は待たせず候補へ出す。普通の強化の枠は一つ残す。
const ready = this.eligibleEvolutions();   // シャッフル
for (const e of ready.slice(0, Math.max(1, this.stats.choices - 1))) choices.push(e.id);
// 残り枠を通常の強化で埋める
```

- **旧仕様のバグも消えた**: 共鳴を目標にすると、条件の揃った他の進化が候補から締め出されていた
- 共鳴は元から自動発現（進化2種が揃うと勝手に開く）。ここは変えていない
- エンジンの `guidancePlan()` `setGuidance()` は削除。`run.guidance` / `initialGuidance` は空文字で残置（保存形式の互換）

### 2.4 削除した機能

| 機能 | 理由 |
|---|---|
| 試射室 | 「このビルドは強いか」を走る前に外で答えてしまう。完成時の快感を前借りする |
| 墓碑の保存枠（6件） | 強いビルドを保存して使い回せると、毎回組み直す前提が壊れる |
| 追憶の祭室・連戦 | ボスを練習できると、走りの中の緊張が抜ける |
| 種子の指定・同種子再挑戦 | 同じ悪夢をやり直せるのはローグライトの逆 |
| 刻んだ道程・直近の被弾 | 開発の計測データをプレイヤー画面に出していただけ |
| 日替わりの悪夢 | 固定装備・祭壇なしで、本質と別のゲームになっていた。跡地に無限の葬送を置いた |
| 墓碑の詳細 | 一覧（到達波・弔具・刻印）は残した |

`source/trial.js` は削除。関数31個を撤去した。

### 2.5 画面

- **戦闘中は上のバーを伏せる**（`#app:has(#play-screen:not([hidden])) #topbar{display:none}`）
- 画面下の操作説明とトグルを削除。**照準・射撃の切替は元から設定パネルにある**ので重複だった
- 盤面の右上に休息ボタン `❙❙`（`#pause-frame`）。上バーの `#pause-top` は撤去済み
- 勝利画面は `THE GOD IS SILENT` を大見出し（最大58px）。日本語見出しと詩と末尾の説明を削除
- **遺灰が減る購入にだけ確認を挟む**（`confirmBuy` → `commitBuy`）。持っている装備の付け替えは無料なので素通し
- PC（`pointer:fine` かつ 900px以上）で盤面1860px、HUDを `clamp` で拡大

### 2.6 スマホ操作

- **横持ち専用。** 縦にすると `#rotate-gate`（横に、構えよ。）が出る。自動停止はしない（作者の指示）
- iOS Safari は向きの固定に対応しないため、全画面時に `screen.orientation.lock('landscape')` を試すだけ（Androidでは効く）。確実に横へ固定したい場合は `manifest.webmanifest`（`orientation:landscape`）があるので、ホーム画面へ追加して起動する
- **なぞって移動**: 触れた点が支点。不感帯9px、74pxで最大速のアナログ。指を戻すと支点が追従
- **なぞる面は盤面ではなく戦闘画面全体**。横の余白で滑らせても端のスワイプ戻りが起きない
- **叩いて跳躍**: 230ms以内・ずれ15px以内
- **跳躍と回避は右下のボタン**（左が回避、右が跳躍）。実機で「右から左へ折り返すと回避が暴発する」と分かったため、払い判定は撤去した
- 大奇跡は中央下。ビルドの確認は指の置き場なので戦闘中は出さず、休息から見る
- 多点対応。左指で移動しながら右指でボタンを押せる
- ボタンの上から始まった指はそのボタンのもの（`e.target.closest('button')` で判定）
- 強化選択は横並び・上寄せ。**出現後360msはタップを受け付けない**（誤タップ防止）
- 定数は `ui.js` の `TOUCH` 一箇所

### 2.7 文言

`VOICE.md` に規則を明文化。要点:

- 正式名称は **BLOOD CHOIR** のみ。副題も日英併記もしない
- 世界観の文は**常体**。保存失敗などのシステム通知だけ丁寧語
- 「〜は変わりません」型の保証文を書かない
- 「テスト版」「仮素材」などの自己申告を画面に置かない

## 4. これからやること

### 4.1 難易度（最優先）

作者の評価: **「敵の攻撃間隔と最初の攻撃が遅すぎて、序盤から撃たれる前に倒せる。最初のステージで飽きる」**
「雑魚の飛ばしてくるものや突進はほとんど見る機会すらない」

原作の設計（`SERAPH-RESEARCH.md` 参照）:

- **敵は4系統×3〜4段階だけ。** 種類を増やさず、同じ系統の上位版に差し替えて硬く強くする
- 本作は14種いるので方向が違う

やること:
1. 雑魚の初撃を早め、攻撃間隔を詰める
2. 波ごとの出現数と耐久の伸びを上げる
3. **既存の敵アトラスから色相をずらした上位種を自動生成**して `Weak/Strong × lvl2/lvl3` 方式に寄せる
   - **Pillow と sharp が両方使える**ので自動化可能。`games/blood-choir/assets/` の敵アトラスが元
4. ステージ（第32波まで）と無限で、伸び方を作り分ける

### 4.2 弾の相殺 — 実装済み（2026-09-23）

自弾にも敵弾にも `guard`（耐久）があり、ぶつかると**耐久の低い方が砕ける**。
勝った側も一つ削れる。総当たりを避けるため64pxの格子で近い弾だけを見る（`collideBullets()`）。

- 自弾 `guard = 1 + min(4, stats.pierce)` — 貫通を積むほど弾幕を押しのけられる
- 敵弾 `guard = 1 + floor(wave/12) + (主なら +2)` — 深く潜るほど、主の弾ほど硬い
- 相殺すると小さな火花（`clash` イベント → 骨色と橙の粒）

効果（深度1・祭壇なし）: 第5波の被弾 23→10、第6波 43→28、第8波に入る時点の残生命 25→50。
主の弾は耐久3なので素の自弾では消せない。

残件: 「敵弾を抜けるたび自弾の威力+25%」（原作のアセンション）は未実装。
自弾の耐久を上げる専用の強化・祭壇も未追加（今は貫通に相乗り）。

# AMBER BOW — 黄昏の弓くらべ

Bowch!の記事の弓対戦仕様を参考にした、オリジナル素材のブラウザゲーム。公開前のローカル版 v0.2。

- 遊ぶ: ゲームセンターのAMBER BOWカセットからPLAY。設置用は `../../games/amber-bow.html`、制作確認用は `index.html`。どちらも画像・コード・効果音を単一HTMLに内包し、直接開ける。
- ローカル確認: http://127.0.0.1:4173/projects/amber-bow/index.html
- 原作記事: https://www.spritefusion.com/blog/making-a-game-boy-advance-game-with-gpt-6-astra
- 元のROM・コード・キャラクター・背景素材は取り込んでいない。

## 遊び方

射角と威力を設定し、敵と交互に矢を放つ。HP100、胴体30、頭45ダメージ。2ラウンド先取。
距離400〜560pxと風がラウンドごとに変化し、同じラウンド内では一定。青い前回の軌跡と着弾距離をヒントに調整する。

PC/タッチ共通: ゲーム画面を押したまま左下へ引くと、方向で射角・長さで威力を設定。離すと発射。画面内ならキャラ付近以外からも開始できる。押した位置へ戻すと取消。引っぱり中は射手の前に方向線と画面上部に数値/ゲージを表示。最大威力までの距離は画面幅に追従。12px未満の操作、逆向き、pointercancel/キャプチャ喪失/多指/リサイズ/停止では発射せず元の設定へ戻す。
PC: ↑↓射角、←→威力、X＋方向で5刻み、Z/Spaceで発射、E長押しで偵察、Vで前の軌跡切替、Enter/Escで一時停止。引っぱり中のEscは取消。
タッチ: 射角・威力スライダーは微調整用として保持、つまみを拡大。発射、偵察切替、軌跡切替。音は初期OFF、右上から切替。

## 素材とアニメーション

内蔵 image_gen で新規生成。

- `art/archers-v1.png`: 1774×887、真のalphaを持つ2人×4ポーズの原本。ローワン=青緑フードの森の射手、レイヴン=鳥型兜の鎧の射手。画像の再加工・色キー抜きなし。
- `art/dusk-forest-v1.png`: 新規生成した夕暮れの森林。原本をそのままHTMLへ内包。
- 全文プロンプトは `art/PROMPTS.md`。
- 待機・照準・発射・被弾の新規絵を状態と時間で切替。待機は微小な上下移動、発射は反動、被弾は押戻し、敗北は足底を支点に倒れる。
- **各動作の全中割りを描いた8フレームアニメではない。4ポーズとプログラム演出の組合せ。** 原本の足底を自動計測してポーズを揃える。元画像の透過は保持。
- 背景は1枚の遠景として遅くスクロールし、地面・草・葉・矢は別速度で動く。背景内の山・森を個別に分離した素材ではない。
- 効果音はWeb Audioで新規合成。BGMは未制作。

## 開発と確認

正本は `source/`。埋込画像のある `index.html` を丸ごと読んだり直接編集したりしない。

```
node projects/amber-bow/build.cjs
node --test projects/amber-bow/test.cjs
npm run verify
```

`build.cjs` は素材原本をそのまま埋込み、構文・script開閉・HTML終端を検査。通常プレイにはNodeやビルドは不要。
13件の専用テスト: 上記に加えて、引っぱりのPC/携帯倍率・方向/威力/上限・取消判定・無風の草の更新と弾道無風の維持を検査。

専用検証URL `?qa=1&scene=aim` / `finish` / `match` は無風450pxの照準済み状態。finishは敵HP30、matchはさらに自分1勝。通常URLに検証用APIは公開しない。
検証URLでは0.25秒/10秒送りボタンを表示し、非表示タブのフレーム抑制に影響されず通常と同じ更新処理で確認できる。
v0.2で無風切替とラウンド/演出時刻/草の変位表示を追加。時間送りも停止・メニュー中は進めない。

2026-09-09: 専用9件PASS、既存公開ファイルの `npm run verify` PASS（初回は別案件vendorの読み取り権限で停止、読み取り検査の権限昇格後成功）。アプリ内ブラウザーで390×844/1280×1000の横はみ出しなし、新規PNG表示、照準キー、偵察中の発射禁止、発射→敵HP70→CPU返射→自分の番、一時停止/復帰、音ONのエラーなし、ラウンド勝利、試合勝利→遊び方→結果復帰→再戦のHP/得点初期化を確認。後半の進行確認は検証URLの時間送り併用。実時間での長時間プレイ、音の聴感評価は未実施。
